# Hope Law Firm: car accident landing page

Static landing page for the Iowa motor vehicle accident campaign. The page is self-contained: index.html plus img/. Form submissions post to the webhook set near the bottom of index.html (lpQuizConfig.webhookUrl). While that value is empty the page runs in TEST MODE and nothing is posted.

Google Tag Manager container GTM-PTXTWHQX is already in index.html.

Source of truth for edits and verification lives in the Paid Media workspace (clients/hope-law-firm/landing-pages/car-accident-ia). Copy the page here after each verified change.
